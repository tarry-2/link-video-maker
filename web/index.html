영상이 완성돼요

대본·이미지·음성·자막·배경음악까지 자동으로. 세부 설정은 안 건드려도 됩니다.

한 편씩 차례로 자동 제작돼요(대본→영상). 완성되면 포트폴리오에 쌓이고, 창을 닫아도 서버가 계속 만들어요.

자동으로 넘어가는 세로 영상 1개 → 릴스/쇼츠에 올려요.

나레이션을 끄면 ‘카드만 집중’ 모드 — 글자 카드가 슬라이드로 넘어가고 배경음악만 깔려요(진짜 카드뉴스).

⚙️ 세부 설정 — 안 건드려도 알아서 잘 나와요 (카테고리·길이·목소리·스타일·나레이션·움직임)

쇼츠 = 세로 9:16 · 롱폼 = 가로 16:9 (유튜브 기준 자동)

자동 = 길이에 맞춰 알아서. 많을수록 장면이 자주 바뀌고 이미지 비용이 조금 늘어요.

🎨 이미지 스타일

모든 탭(영상·카드뉴스·하이라이트)에 적용돼요. '자동'은 디자인에 맞는 글씨체가 자동 선택되고, 하나 고르면 제목·후킹에 그 폰트가 들어갑니다. 자막은 가독성을 위해 깔끔한 고딕 고정.

상품 정보 고정 (판매 영상용)

상품 사진을 그대로 사용하고, 입력한 정보를 영상에 고정 표시합니다. AI가 가격이나 혜택을 새로 만들지 않습니다.

버튼을 누르면 먼저 대본을 만들어 보여드려요. 확인 후 이미지·음성 제작이 이어집니다. 입력한 내용은 새로고침해도 유지돼요.

  • 🎞 카드 종류 — 표지·큰숫자·리스트·인용·비교·실수vs해결·마무리를 AI가 섞어줘요
